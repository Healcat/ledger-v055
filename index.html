转账统计 0

按交易对方汇总微信/支付宝「转账」：每个对象列出其名下全部转账记录（转出/转入，含小额），并统计净支出与净收入。点击对象名可展开/收起明细；每个大模块可「删除」以在本统计中隐藏（仅影响本卡片展示，不改变实际支出总额）；底部「还原全部」恢复。相互转账且转出多于转入的部分仍会在实际支出总额中自动抵扣（单笔转出 ≥500 参与抵扣）。其中「2 笔以上（每笔≥500）相互转账」的对象标记为多次转账（智能分类仍属「人情往来」，可在上方「分类」下拉或筛选去除中单独筛选）。仅展示转账总额 ≥1000 的对象。

怎么用

  1. 微信：我 → 服务 → 钱包 → 账单 → 右上角「…」→ 账单下载，导出 xlsx 或 csv。
  2. 支付宝：我的 → 账单 → 右上角「…」→ 账单下载，导出 xlsx 或 csv。
  3. 把文件拖入上方区域，应用会自动识别并合并。
  4. 程序会自动只保留「实际支出」（支出 + 支付成功/已转账/还款成功 等，排除 收入/退款/交易关闭/投资理财），并自动核减支付宝的部分退款。
  5. 核对智能分类（可逐条改），看扇形图了解支出占比；顶部可切换「月度 / 年度」统计周期，并查看单笔 / 类别支出排行；退款核减详情会在「退款核减明细」中滚动展示。
  6. 点「导出 CSV」得到 ledger_unified.csv。
  7. 用 python examples/classify.py ledger_unified.csv 做后续 Python 分析。

没有账单？点「加载示例数据」立即体验完整流程。
